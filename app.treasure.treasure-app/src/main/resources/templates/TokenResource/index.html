Use Treasure from Claude

Register Treasure as an MCP server and Claude can look up, create and change devices and assign them, as you. Replace YOUR_KEY with a key created above.

claude mcp add --transport http treasure {mcpUrl} --header "Authorization: Bearer YOUR_KEY"

Claude then has list_devices, get_device, device_history, list_members, overview, create_device, update_device, assign_device, unassign_device, add_member and update_member. API keys are for admins only; a key stops working when it does not carry the admin role.
